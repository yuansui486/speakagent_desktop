# Bundled PDF fonts

`NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` are static weight-400 and weight-700 instances of Google Fonts Noto Sans SC, generated with fontTools varLib.instancer from:
https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf

They provide Simplified Chinese, Latin, and Cyrillic glyphs for offline PDF export. See `NotoSansSC-LICENSE.txt` for the SIL Open Font License 1.1.

DejaVu remains the default face for Latin, Cyrillic and symbols (including task checklist glyphs). CJK runs use Noto Sans SC, with a true bold face for headings. Both font families are embedded; no installed fonts or internet connection are needed for export.
